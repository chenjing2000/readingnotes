# MVP 验收测试（必须可复现）

以下测试至少提供自动化 E2E 或明确手工复测步骤；截图须来自实际运行的编辑器，不得用参考 HTML 冒充。

## A. 内容与持久化

1. 导入 `projects/brainco/project.json`，文章恰有 2 个真实自然段；全部原文字符顺序与 `article.md` 一致（不计换行规范化）；中文译文也恰有 2 段，完整保留全部语义。
2. 修改第二段中 `supposedly` 前后文字，保存项目到 JSON，关闭并重新加载，改动仍存在；可撤销/重做。
3. 在英文原文中选中并加亮一个词组，取消一次，确认显示及存储同步；人工取消其中一处的高亮不应误取消另一处同词高亮。
4. Vocabulary 增删改及拖动/排序；Useful Expressions 修改其英文例句和中文译文；Main Idea 改写；保存重载保持一致。
5. 清空某一译文段落时应提示或保留空段占位；不得悄悄截断其他段落。

## B. 排版与跨页

6. 画布截图物理分辨率严格 1200 × 1600，背景为 `#f8f8f6`，页码正确且不覆盖内容。
7. 修改字体后重排，不出现内容溢出、滚动条、截断或重叠。英文重点字号必须跟随英文正文变化（例如正文改为 34px 时高亮也为 34px）。
8. 在单个 Useful Expressions 例句插入 150–250 英文单词（独立测试数据），**同一个例句自身**可在文字行边界跨页；逐字校验生成结果与输入相同且无重复/丢失。
9. 人为调整前页可用空间，令短语在第 N 页底、中文含义和例句从 N+1 页开始；不得因为同一条表达而强制整条移到下一页。
10. 中文自然段长度超过一页时可跨页，**续页首行不再额外缩进**。英文第二段跨页也遵循相同规则。
11. Main Idea 和 Translation 可以同页相接，无强制分页；模块标题及横线只在开始处出现一次。
12. 每一页最后一行完全在内容容器内；页面之间没有吞字、重字、断词。词汇两栏均匀分配，项目数据变更后仍两栏。
13. 页面内容较少时不能硬凑固定页数；内容过多时可以超过 10 页。
14. 长无空格英文 token / 中英文混合文本 / 超长中文标点边界不丢文字；极端单词允许折行或可理解警告。

## C. 导出与运行

15. PNG 图片数量 = 预览页数量，且每页 PNG 与预览一致；ZIP 可正常解压。
16. 多次导出同一份未更改项目，页数、内容和版面不发生随机漂移；字体未就绪前不能截图。
17. Windows PowerShell 下按 README 命令全新安装后可以本地运行；无需联网调用外部 API 处理私有文章（首次安装 npm 包除外）。
18. 导入无效 JSON（坏版本、缺失字段、乱码等）报告可读错误而非白屏。
19. 重启浏览器/重载后有清晰的保存状态；未保存改动不会被“重新渲染”默默抹掉。
20. 执行 `npm test` 和 `npm run test:e2e`（或文档列出的等价命令）时输出真实结果；实现报告列出任何未通过项目。

## 优先级

P0：1、2、4、6、7、8、9、10、11、15、17、18。
P1：其余条目。任何 P0 未通过不应宣称 MVP 完成。
